```python
import subprocess
def factor_with_yafu(n):
    command = f'echo "factor({n})" | yafu'
    result = subprocess.run(command, shell=True, capture_output=True, text=True)
    return result.stdout
```

**factordb** - Online factorization database:
```python
import requests
def queryFactors(n):
    s=[]
    url="http://factordb.com/api?query="+str(n)
    r = requests.get(url)
    factors=r.json()['factors']
    for f in factors:
        for i in range(f[1]):
            s.append(int(f[0]))
    return s
```

**flatter** - Fast lattice reduction:
```python
from subprocess import check_output
def flatter(M):
    z = "[[" + "]\n[".join(" ".join(map(str, row)) for row in M) + "]]"
    ret = check_output(["flatter"], input=z.encode())
    return matrix(M.nrows(), M.ncols(), map(int, findall(b"-?\\d+", ret)))
```

## DeepSeek Tool Strategy
Use this decision tree before every action:

**RSA challenges:**
- Small e (e=3, e=17)? → Cube/eth root attack with SageMath `iroot(c, e)`
- n easily factorable? → Try factordb first, then yafu
- Multiple ciphertexts, same n different e? → Common modulus attack (Extended GCD)
- d is small? → Wiener's attack with continued fractions
- p, q close together? → Fermat factorization
- Coppersmith hint available? → SageMath `small_roots()`
- Otherwise → Write a complete Python script using gmpy2 or sympy

**Lattice challenges:**
- Always use flatter over LLL for speed
- Build the lattice matrix in SageMath, call flatter, extract solution

**ECC challenges:**
- Check curve order for small subgroup attacks
- Check if parameters are standard (secp256k1, P-256) or custom/weak
- Use SageMath's built-in `EllipticCurve()` for all curve arithmetic

**Stream/PRNG challenges:**
- Identify the PRNG type first (Mersenne Twister, LCG, etc.)
- For MT19937: collect 624 outputs to clone state
- For LCG: solve with modular arithmetic

**Block cipher challenges:**
- Identify mode (ECB, CBC, CTR) from ciphertext patterns
- ECB: look for repeated blocks
- CBC: bit-flip or padding oracle if applicable

**When to use each tool:**
- SageMath → number theory, polynomial rings, elliptic curves, lattices
- Python + gmpy2 → fast big integer arithmetic, RSA operations
- yafu → factoring n > 40 digits that factordb doesn't know
- flatter → any lattice reduction task
- factordb → always try this first before factoring locally
